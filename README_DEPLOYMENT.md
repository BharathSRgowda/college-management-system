## 📞 Support & Troubleshooting

### If you face issues:

1. **Check Logs**:
   - Vercel: Dashboard → Deployments → Logs
   - Render: Dashboard → Service → Logs

2. **Common Issues**:
   - Backend sleeping: Wait 30 seconds
   - CORS error: Check backend URL in frontend
   - Login fails: Verify environment variables

3. **Documentation**:
   - Read DEPLOYMENT_GUIDE.md troubleshooting section
